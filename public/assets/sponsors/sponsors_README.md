# Logos de patrocinadores

Coloca aquí el logo de cada patrocinador, con el nombre exacto que indica esta
lista (generado automáticamente a partir de su nombre real — ver
`src/utils/sponsorAssets.js`, función `sponsorId`).

No he generado ni incluido los logos reales de los patrocinadores: son marcas
registradas de terceros (Monster Energy, Red Bull, Castrol, etc.) y no puedo
reproducir logotipos oficiales con derechos de autor. El sistema de carga
automática ya está implementado y funcionando — solo falta que añadas aquí tus
propios archivos.

## Especificación

- Formato PNG, fondo transparente.
- Logo horizontal o cuadrado, tal como en la referencia del panel "Mi Moto".
- Nombre de archivo exacto según la lista de abajo.

En cuanto coloques un archivo con el nombre correcto, aparecerá
automáticamente en el juego — no hace falta tocar ningún componente. Si el
archivo todavía no existe, se muestra el nombre del patrocinador en texto.
