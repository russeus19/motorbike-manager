# Logos de fabricantes

Coloca aquí el logo de cada fabricante/chasis, con el nombre exacto que
indica esta lista (ver `src/data/manufacturers.js`).

## Especificación

- Formato PNG, fondo transparente.
- Logo cuadrado o casi cuadrado — se muestra en un círculo/marco redondeado.
- Nombre de archivo exacto según la lista de abajo.

En cuanto coloques un archivo con el nombre correcto, aparecerá
automáticamente en el juego — no hace falta tocar ningún componente. Si el
archivo todavía no existe, se muestra un icono de fábrica genérico en su lugar.
