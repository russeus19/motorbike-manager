# Fotos de revelación de moto por fabricante

Usadas en la pantalla de bienvenida de temporada ("aquí está tu moto nueva"),
mostrada al empezar cada temporada de MotoGP.

## Especificación

- Formato JPG.
- Pensada como una silueta de moto completamente en negro, con el nombre
  de la marca — el estilo típico de una "revelación" antes de aplicar la
  decoración/librea real de cada equipo.
- Orientación horizontal, la moto mirando hacia la derecha (misma
  convención que el resto de fotos de moto del juego).
- Nombre de archivo exacto según la lista de abajo.

En cuanto coloques un archivo con el nombre correcto, aparecerá
automáticamente en el juego. Si el archivo todavía no existe, se muestra un
icono genérico de moto en su lugar.
